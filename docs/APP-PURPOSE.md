# Vault Folio

Vault Folio is an inheritance guide. It helps an owner write down how a bitcoin setup is arranged so heirs, an executor, or counsel can rebuild it later.

It stores the map, not the treasure. It does not create keys, sign transactions, or ask for a seed, a private key, or an xpub.

The real app is the desktop program `vault-folio.py`. It is meant for an air-gapped machine. It seals the guide in an encrypted file. A normal launch stays locked unless the machine reports no network route, no active interface, and no Wi-Fi or Bluetooth hardware.

## Browser preview

`browser-edition/preview.html` is a functionality preview for other developers. It runs online in a browser. It is not the app.

Do not enter a seed, a private key, a real passphrase, or a private plan. The full browser copy is `browser-edition/app.html`. It walks the interview, the sheets, the risk note, the passphrase window, and the heir view. It is still an online preview. Do not enter a real plan. A file it downloads is a demo, not a desktop Vault Folio seal.
